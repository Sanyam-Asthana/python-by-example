You can take user-input using input() and store the entered input into a variable. The argument of the input() function is treated as the prompt to the user. You can omit the argment to display no prompt.

You can then use that stored input in any way.

By default, the input() function takes input as a string. You can parse that input into a different data-type by using the data-type specific function. For example, to parse it into an integer, you would wrap the statement with int().

You can then use the parsed value as a normal variable in any way.
