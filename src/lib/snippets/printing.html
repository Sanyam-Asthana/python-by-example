Each print statement prints a new-line character by default.

You can change this behaviour using end argument

Use print() to print a blank line

You can print numbers by not keeping them in quotes, and operations work as intended.

You can easily concatenate multiple strings (or other data types) together by providing them as separate arguments in print().

The arguments of print() are separated by a space by default. You can change that behaviour by using the sep argument.

Strings can also be enclosed in sinlge quotes instead of double quotes.
